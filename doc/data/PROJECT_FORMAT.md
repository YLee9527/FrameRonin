# 项目格式 1

独立抠图 `kind=image-matte`、`formatVersion=1` 保存 mode、settings、view、source/black/white，以及 raw/repaired/eroded 三阶段结果。图片和报告只保存 `{versionId,name,type}`，每个结果另保存有序 inputs 和 taskId。raw 必须来自当前选定原件；repair 来自 raw 图片，frontier 来自 repaired 图片。恢复先核对字段、资源元数据、成功任务及输入输出顺序、模式/参数和尺寸，再按预算读取并核对报告。未知字段、路径、身份别名和不合法链直接拒绝。当前参数可不同于上次结果，界面明确显示尚未应用。

输入、参数、背景、完整缩放/平移手势和三个结果阶段共用 50 步/256 MiB 文件历史；保存重开与撤销重做只复用已有版本。侵蚀归零移除当前 eroded 引用，保留修复版本及全部正式文件。只有本次界面输入或参数编辑启动自动加工，重开/历史操作不启动任务。取色/导入等待期间的新编辑合并到执行快照；快照之后的编辑另行调度，避免同组参数重复加工。修订冲突及迟到读取沿用共享保存保护。

调整器使用 `kind=sheet-adjust`，Pro 使用 `kind=sheet-pro`，payload 均为 `formatVersion=1`。保存原图、当前预处理和帧 ZIP 的正式版本、实际帧尺寸、稳定帧 ID/源索引、选择、偏移/计数、逐帧及统一裁边、播放设置与固定像素提案。历史导出额外保存当时的输入 ZIP 引用，不能误认作当前编辑结果。

`lineage` 只保存按顺序的任务 ID；恢复核对原图→可选预处理→拆分→修补/原帧归档的成功输入输出链，禁止未知操作、跳步和其他素材。准备配方单独保存，当前参数可以尚未应用。通过受控任务元数据清单核对历史，不下载所有中间 ZIP；当前及仍引用的结果按预算读取并校验报告。来源链最多 8192 步、4096 当前帧；没有 blob URL 或用户路径。

编辑历史覆盖输入、预处理/拆分设置、选择、偏移计数、完整拖拽、删除、空白帧、统一裁边、固定像素和已有导出版本。手势合并、有界文件/状态历史、保存冲突及迟到读取保护沿用共享文档机制；恢复和撤销重做不触发加工。原图、网格或预处理的自动加工只由本次明确的界面编辑触发；取消或未完成的草稿重开后需明确重试。

精灵表 `kind=sprite-sheet`、`formatVersion=1` 保存 source、info、activeTab、columns/rows、duration、framesPerRow、原网格索引 order，以及 split/frames/gifs 三类既有结果。每类结果为 `{data,report,taskId}`，最多七个唯一资源，均使用正式版本引用；当前分组、顺序或时长可不同于上次 GIF，界面提示重新执行才应用。恢复先核对源图元数据、完整预算、成功任务输入和输出顺序、报告与实际网格/行结构，再读取文件。改网格清空准备帧及 GIF，保留上次拆帧 ZIP。

输入、完整拖拽、键盘排序、删帧/删行、网格及参数、三类结果共用 50 步/256 MiB 文件历史和 64 MiB 状态预算；结果重做复用文件。未结束的可见帧手势即使尚未移动，也阻止迟到读取及加工覆盖。另存使用新 ID，修订冲突阻止导航。关闭整个宿主浏览器仍会终止 Worker，离开工具页则由任务管理器保留正在执行的加工。

`project.json` 存储格式版本、项目 UUID、名称、语言与创建时间。`project.sqlite` 使用 SQLite WAL；`.write.lock` 保证单写入者。`assets/` 保存不可变版本文件，`tasks/` 保存输入副本、输出、日志和指标，`exports/` 为交付目录，`.pending/` 保存未完成落盘。项目内部只接受相对路径，拒绝遍历和符号链接。

素材具有稳定 UUID、名称和当前版本；版本具有 UUID、所属素材、父版本、相对路径、SHA-256、解码元数据、来源和时间。切换版本保留全部文件。元数据包含尺寸、帧数、时长、透明度、处理尺寸和有界缩略图，素材列表不加载原分辨率大图。

任务记录操作、输入版本、参数、状态、执行代次、进程身份、进度、结果和错误。持久化调度队列位于技能私有 `.runtime/`，同一安装串行加工，等待任务不启动处理进程。PID、创建时间及命令必须符合应用身份才能终止进程。

导入先复制、完整解码、校验和登记待完成记录；原子重命名并在事务中登记正式版本。多产物全部完成校验后统一发布。完整哈希读取在写入锁外进行，锁内重新检查文件身份、任务状态和执行代次。启动恢复保留并报告未完成记录、孤立文件和无任务记录的目录；不自动把不明确的任务输出登记成功。

文档记录类型、修订号、JSON 内容与时间；每次保存比较预期修订并追加历史。Rseprite 格式 1 保存尺寸、层 ID/名称/状态、帧 ID/时长，以及每层的素材版本引用。像素保存为 PNG 版本；帧/层 ID 唯一、引用有效、尺寸一致，限制 2048 边长、32 层、1000 帧和 256 MiB 文档像素。历史最多 50 步，同时受内存上限约束。

同一文档 ID 的类型不可变；不同类型必须另存新 ID。服务端保存有限大小的 JSON 包络、类型与修订，具体文档格式在对应序列化及恢复入口严格校验，不能把已写入 JSON 视为可执行或可编辑内容已经有效。

提案保存严格任务、预览、输入 SHA 和当时素材版本、已执行任务 ID；执行核对修订及素材变化，并在登记任务的同一事务中领取该修订。AI 尝试保存样本、模板、提示、选定参考、次数、宿主状态、质量结论及结果版本。AI 结果通过统一完成接口登记，本地取消与服务端状态分别记录。

## 蓝图文档

workflow 文档 payload 使用 formatVersion 1，graph 使用历史迁移后的 version 7，保存节点、连接、参数、位置与预设名称；inputs 保存稳定输入 ID、原文件名及正式素材版本 UUID。只保存副本和版本引用，重开不重新导入同一素材。历史长连线 ID 与可编辑的未完成布局可以保存；执行及 AI 提案仍走严格语义校验，不能把可保存误认为可执行。

蓝图撤销覆盖节点/连接/参数/名称；删除节点及相关连接为一步，拖动的完整手势为一步，最多 50 步并受 64 MiB 估算上限约束。打开另一文档清空当前撤销栈。旧 JSON 导入显示迁移/修正；AI 提案的未知字段、长度、类型和执行语义不因此放宽。

读取先准备候选内容，核对期间没有新编辑后才应用；被拒绝的候选释放临时资源。Rseprite 的素材缓存也只在接收该文档时启用，避免迟到读取改写当前帧的版本映射。保存失败保持当前内容并阻止导航，可另存副本。

共享保存条支持 Command/Ctrl+S 保存、加 Shift 另存副本；输入法组合期间不拦截快捷键。保存及重开后选择框显示当前文档，读取候选被拒绝或界面退出时释放暂存资源。

地图文档 `kind=map`、`formatVersion=1`：`source` 和 `tileUploads` 保存 `{versionId,name}`，不保存本机路径或 blob URL；`tiles` 以四位小数规范坐标键记录 `{x,y,w,h}`。`tileFeathers` 为上下左右 0–50%，另保存重叠比例、4/8/12 分扩展设置、边框和图块显示状态。可选 `view` 保存平移坐标、0.05–8 缩放及有效选中图块。旧文档没有 view 时使用默认视图。

地图历史最多 50 步、保留图像估算上限 256 MiB；相同图片引用不重复计费。过去、现在、未来和未结束手势共用图片生命周期，只有不再被引用时才释放浏览器 URL。重开通过版本内容校验和有界预览检查。旧 JSON/ZIP 是独立的便携兼容格式；其中图像作为新导入副本，不把旧文件引用当成本机读取路径。

## 序列文档

`kind=sequence`、`formatVersion=1` 保存 GIF 输入、帧数组、拆分输入、合成及拼接输入、参数和已有结果；每个文件为 `{versionId,name,type}`，不存本机路径或 blob URL。同一文件可被多个入口引用，重开和重存复用正式版本。校验字段、媒体类型、帧数、参数、结果尺寸及读取预算。

排序、增删帧、空白帧、参数和加工结果使用同一撤销栈，最多 50 步、历史压缩文件估算 256 MiB。结果撤销/重做保留已有文件，不重新执行加工。Tab 导航保存视图但不单独增加撤销步。已验证保存冲突阻止导航、另存重开、读取期间编辑保护，以及 1000 帧排序、时长撤销重做和引用复用；联合内存实测与其余编辑器继续验收。

## 像素加工文档

`kind=pixel`、`formatVersion=1` 保存原件及已有结果的 `{versionId,name,type}`、实际处理尺寸、原图坐标选区、五种模式参数及当前页签。不保存路径或 blob URL。加载核对字段、文件类型及大小、解码尺寸、参数范围、选区和正式内容；结果可保留上次加工状态，同时继续修改参数。

输入替换及清空结果作为一步；完整参数拖动作为一步；原件、选区、参数、已有结果共用撤销和重做。重开清空旧撤销栈，页签保存但不增加步骤。结果重做复用原版本，不重新加工。

像素和序列文档共用文件保留预算：当前、过去、重做及未结束手势按唯一文件估算，256 MiB 超限优先裁剪最远历史。当前文档不因此丢弃；新操作另按完整资源预算判断是否可运行。单独计算撤销与重做造成的低估已修正。

## RoninPro 图像工具文档

统一尺寸 `kind=ronin-unify`、切分查重 `kind=ronin-duplicates` 和自定义缩放 `kind=ronin-scale` 使用 `formatVersion=1`，保存 tool、parameters、files、results、reportFile、taskId、editedFile。文件统一引用 `{versionId,name,type}`；前两种工具的 editedFile 必须为 null。缩放文档可另存与加工结果同尺寸的精细编辑 PNG，原件和加工版本继续保留。

输入和结果必须属于正式项目。已有结果及末尾 JSON 报告的顺序、操作、输入版本必须与成功任务完全一致；报告额外核对帧数、格子尺寸、分组唯一性和索引范围。查重允许最多 4096 个结果，与其他序列的 1000 帧限制分开。重开先检查完整引用和读取预算，最多八个并行读取；候选内容通过后才替换当前文档，不生成任务或重复导入素材。

输入替换/删除、参数手势和完整加工结果共享有界撤销栈；重做直接复用已有版本。当前、过去、重做和未结束手势共用 256 MiB 文件预算，最多 50 步。结果可保留在当前参数变化之前的版本，界面明确提示重新执行才应用新参数。保存修订冲突阻止导航，另存使用新 ID；读取期间的新编辑不会被迟到候选覆盖。

缩放文档的画笔/橡皮完整笔画、连通擦除、选区移动及重置同样进入该文件历史。保存、重开、导航、输入替换、加工和撤销前先完成待保存画布；PNG 编码失败或取消时保留像素并阻止该保存。未编码笔画也显示为未保存；自动保存等待完整笔画结束。用户可以明确重试或放弃尚未保存的绘制，不能静默清除。另存只有在新文档写入成功后才切换当前 ID。

## 独立精细图片文档

`kind=image-fine` 沿用上述格式 1，`tool=fineEdit`、`parameters={}`，最多一个源文件；`results=[]`、`reportFile=null`、`taskId=null`。`editedFile` 可为空或引用正式 PNG，其尺寸必须等于源图的实际画布尺寸。该入口直接保存编辑版本，不伪造后台加工任务。输入替换、删除、完整笔画、连通擦除、选区移动与重置共用文档历史；下载不改写原件引用。

源图先校验静态 PNG/JPEG/WebP、20 MiB 上限及完整像素预算，再替换当前文档。原件元数据保留编码尺寸，并增加 `orientation`、`displayWidth`、`displayHeight`、`containerFormat`；缩略图按 EXIF 正向显示，文件内容不变。旧 JPEG/WebP 索引在读取时补充这些字段，不改数据库。精细画布保留原浏览器的格式行为：JPEG/PNG 应用方向，WebP 保留编码方向；固定方向样本分别为 12×16、12×16、16×12。其他方向与浏览器仍需补充验证。

转入蓝图结果时沿用已核验的正式版本；改文件显示名称不触发重复上传。导航保存失败不切换页面或提示转入成功。重新打开先检查尺寸、格式、预算及引用，再读取内容；导出始终从画布编码真实 PNG。

## 常规图片文档

`kind=image-normal`、`formatVersion=1` 保存 `settings`、`source`、`preview` 和 `matte`。源文件使用 `{versionId,name,type}`；主结果及抠图辅助结果分别保存 `{file,input,report,taskId}`，其中三个文件仍是正式版本引用。普通加工与一键配方读取源图，底部扩展读取上一张主结果；保存真实任务输入，避免重开后丢失扩展来源。主结果与辅助预览互不覆盖。

字段、UUID、文件名、参数、格式、尺寸和读取预算严格校验。恢复前核对任务成功、操作为 image.normal、输入版本及 PNG/报告的完整输出顺序，按模式核对结果尺寸与角色，再读取最多七个唯一文件资源。报告参数须匹配实际任务。已有版本不重新导入，重开不重新加工。

源图替换/删除、裁切及参数完整手势、取色和两类加工结果共用 50 步/256 MiB 文件历史。撤销及重做复用已有文件；导出不会随历史删除。保存、重开、导航与撤销先结束裁切手势并等待取色，读取中的新编辑或未结束手势阻止迟到候选覆盖。保存修订冲突保留当前内容并阻止导航，可另存副本。

## 网格扩图/缩图文档

`kind=image-expand-shrink` 使用共享图像工具格式 1，`tool=expandShrink`，参数为 columns、rows、cellWidth、cellHeight。最多一个原件和一个 PNG 结果，editedFile 为 null；结果及报告绑定原成功任务。当前参数可以不同于旧结果参数，恢复按原任务核对 PNG 尺寸，并提示重新执行才应用新参数。

恢复先检查字段、格式、源文件上限、读取预算和任务/版本绑定，再读取内容；报告参数核对实际任务。输入替换、四个参数的完整手势与已登记结果共用 50 步/256 MiB 历史，重做与重开复用已有版本。另存使用新文档 ID，已导出文件继续保留。

## 零散切图文档

`kind=scatter`、`formatVersion=1` 保存 source、info、settings、boxes、selectedId、detection 和 archive。源图使用 `{versionId,name,type}`；info 保存原显示尺寸和文件名基部。settings 包括识别、编辑/新增工具、格式/质量、命名、排序、缩放及尺寸标签。画框使用稳定 ID 和原图坐标，最多 4096 个，必须在图内且宽高至少 1px。

detection 和 archive 分别为 `{data,report,taskId}`，引用正式 JSON/ZIP 及报告；重开先核对成功任务、源版本、完整结果顺序、格式、尺寸与读取预算，再读取最多五个唯一文件。手动修改画框不必重新识别；当前参数与上次 ZIP 可以不同，界面明确提示重新执行才应用新参数。

源图替换、完整画框手势、删除/清空、名称/参数及已有结果共用 50 步/256 MiB 文件历史，另限制 JSON 历史估算 64 MiB。保存/打开/导航/撤销前结束当前手势并等待输入准备。修订冲突和读取期间的新编辑保留当前内容，可另存副本；重做或重开直接使用已有 ZIP，不生成任务或版本。导出文件不随撤销删除。

## 自定义切图文档

`kind=custom-slice`、`formatVersion=1` 保存原图及尺寸、自动/网格/区域模式、稳定区域 ID、完整 L7 边界/行带偏移/单行折线、重排矩阵与四向补边。方案、切图 ZIP、合成 PNG 分别为 `{data,report,taskId}`；合成另存 `input`，必须引用当前切图 ZIP。最多七个唯一文件资源，重开不把 ZIP 内各帧另行导入。

恢复先严格核对字段、唯一区域 ID、几何、参数、资源格式/尺寸/读取预算，再核对三个成功任务的操作、输入版本和完整输出顺序。读取后核对方案格数、每帧尺寸、报告参数及合成尺寸。允许保存尚未完成的区域草稿，实际执行仍拒绝图外起点；当前参数可以不同于上次结果，界面提示明确重新执行才应用变化。

源图替换/删除、区域与参数完整手势、L7 拖拽、TXT 导入、扩边预设和已有结果使用同一 50 步/256 MiB 文件历史，JSON 历史另限 64 MiB。重做复用已有结果，不重新生成。保存/读取/导航/撤销等待输入准备和 TXT 读取，并结束切线手势；读取中新的编辑及按住但尚未移动的手势均阻止候选覆盖。修订冲突保留内容并阻止导航，可另存新 ID。导出文件继续保留。

## 图片可见水印文档

`kind=image-visible-watermark` 沿用共享图像工具格式 1，`tool=visibleWatermark`，parameters 仅含 `sizeMode=auto|48|96`。最多一个原件、一张 PNG 结果和一个 JSON 报告，editedFile 为 null。结果绑定原成功任务的操作、输入和完整输出顺序；恢复先核对静态格式、尺寸和读取预算，再下载内容，报告参数必须与实际任务匹配。

输入替换/删除、尺寸选择和已有结果共用 50 步/256 MiB 文件历史。当前尺寸选项允许不同于旧结果；提示重新执行，重做及重开直接复用版本。输入准备未完成时保存等待；读取期间参数变化保护当前内容，修订冲突阻止导航并允许另存。导出仍使用完整 PNG，预览使用有界缩略图。
