# 本地排障

| 现象 | 处理 |
| --- | --- |
| Skill 未发现 | 核对技能目录和名称，重新加载 Codex 的技能列表；已有远程 frameronin 不是新技能 |
| doctor 依赖缺失 | 使用指定 Python 3.11 执行 setup；不要将用户全局环境作为私有依赖环境 |
| 工作台打不开 | 检查 serve 返回地址和端口，以及工作台构建；服务仅在 127.0.0.1 开放 |
| 大图/多帧拒绝 | 查看操作预算与处理方式，调整参数；PerfectPixel 保留 2048 预缩放，不默默改变其他算法语义 |
| 保存修订冲突 | 保留当前编辑器，另存文档副本；不要覆盖另一写入者已保存的版本 |
| 任务中断 | 查看 status 和 recover；保留日志和孤立文件，不把残留输出强行标为成功 |
| ImageGen 不可用 | 检查宿主工具目录与登录；保留本地加工，不自动切换代充或其他提供方 |
| AI 状态未知 | 检查原调用及产物，再标记最终状态；不要自动重生成 |
| AI 取消后仍有文件 | 本地登记已失效，核对宿主最终状态；不得把迟到结果登记成功 |
| 原生软件无法检查 | 记录具体原因与未验收范围；Mac 锁屏需要用户解锁，构建成功不能替代 Krita/原生交互验证 |

错误包含稳定 code、说明及必要参数。提交诊断前脱敏路径和用户提示，勿附认证、环境秘密或私人素材。
