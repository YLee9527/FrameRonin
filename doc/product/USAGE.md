# 产品与使用

通过 `$frameronin-local` 描述目标、参考图、像素尺寸、动作和输出格式。已有项目沿用目录；新项目使用空目录初始化。原件导入为副本，加工结果追加版本。

绘制、图层、时间线、蓝图连接和地图布局在本地工作台完成。运行技能的 `serve --project <目录>`，打开返回的本机地址。顶部切换中、英、日；快捷键为 Ctrl/⌘ + Alt + 1/2/3。输入文字时避免编辑快捷键干扰。

右下角“项目素材与任务”用于导入、查看结果和取消后台加工。取消立即显示反馈，本地结果先失效，再停止计算。ImageGen 的服务状态需回到 Codex 核对；本地取消不能证明服务端已经停止。

Rseprite 支持画笔、橡皮、已有图层状态、帧复制和删除、时长、洋葱皮，以及统一撤销/重做。更改后自动保存；离开前再次保存。可手动保存、打开文档或另存副本。保存冲突时保留编辑器和内容。原仓库未实现的播放与导出列入路线图排除项。

旧蓝图导入显示迁移及丢弃项。AI 自然语言流程先保存严格提案并预览，再按用户明确指令执行。已执行修订关联固定任务；再次执行应先检查原任务，必要时修订并重新预览。

PSD 在 Krita 检查图层、透明度和合成；Godot 的自动导入与运行仅用于固定可信工程和既有导出器。AI 新生成脚本先审阅，再取得运行授权。

当前实测范围见 [验收记录](../testing/SKILL_ACCEPTANCE.md)，操作来源与未完成项见 [功能对照](../baseline/FEATURES.md)。
