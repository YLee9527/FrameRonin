# 产品与使用

通过 `$frameronin-local` 描述目标、参考图、像素尺寸、动作和输出格式。已有项目沿用目录；新项目使用空目录初始化。原件导入为副本，加工结果追加版本。

绘制、图层、时间线、蓝图连接和地图布局在本地工作台完成。运行技能的 `serve --project <目录>`，打开返回的本机地址。顶部切换中、英、日；快捷键为 Ctrl/⌘ + Alt + 1/2/3。输入文字时避免编辑快捷键干扰。

右下角“项目素材与任务”用于导入、查看结果和取消后台加工。取消立即显示反馈，本地结果先失效，再停止计算。ImageGen 的服务状态需回到 Codex 核对；本地取消不能证明服务端已经停止。

“控制测试”的俯视和街机场景分别保存文档。可更换一图全动作角色图、背景和音乐，街机另支持前景；未选择素材时使用随包默认资源。点击场景后 WASD 移动、Shift 跑步、I/J/K 测试物品/吸引/防御；聚焦保存控件或离开窗口后不会继续误移动。开启“障碍物编辑”后拖拽绘制碰撞矩形，可清空并撤销/重做。

“将当前位置设为起点”将位置和朝向纳入文档，“重置角色”回到该起点。保存原件版本、碰撞区、编辑模式、音乐开关和起点；实时按键、动画进度和随机怪物不持续写入，重开后重新开始模拟。支持保存/重开/另存、统一历史和冲突保护。加载可取消并重试，音乐自动播放被浏览器阻止时可点击播放；失败不会显示为播放中。全屏中仍可用 Ctrl/⌘ + Alt + 1/2/3 切换三语。

“抠图去背”包含绿/蓝幕、白底和双背景。上传或修改加工参数会自动调度受控任务；取消后可明确重试。点击绿/蓝幕原图从原像素取色，预览最长边 1024 不改变导出尺寸。双背景的黑、白图片尺寸必须一致；去背景后可修复透明边缘，再调侵蚀。每次侵蚀从修复版本重算，归零复用已有修复结果。右键拖动及滚轮调整双背景预览，数字输入提供平移/缩放替代；视图不修改 PNG。支持项目保存、另存、重开及统一撤销重做，已有结果不重新生成。离开工具后加工继续，完成结果可从项目面板下载；关闭宿主浏览器会终止 Worker。“发送到暂存”及下载已验证，画布原生拖入暂存仍待确认。

Rseprite 支持画笔、橡皮、已有图层状态、帧复制和删除、时长、洋葱皮，以及统一撤销/重做。更改后自动保存；离开前再次保存。可手动保存、打开文档或另存副本。保存冲突时保留编辑器和内容。原仓库未实现的播放与导出列入路线图排除项。

“Sprite Sheet 调整”拆分后默认激活前 6 帧，支持单帧、整行、整列选择和动画预览。聚焦工作区后用 A/D 切换、Q/E 向两侧扩选、Shift+Q/E 缩选，方向键微调当前帧；输入框内不响应这些编辑快捷键。固定像素从原始帧读取，点击“应用到选中帧”才追加加工版本。

RoninPro 的“单图调整 Pro”增加水印/内裁/补边/最近邻/抠图预处理、透明拆分、帧拖拽、删除及空白帧；空白帧使用当前首帧的原始尺寸。调整排列列数不重新切图，统一裁边允许负数透明扩边。修改原图或整图网格会启动新拆分；透明模式先更新预处理预览，再点击“拆分 / 重新应用”。PNG 合成及 GIF 应用偏移与裁边，“原帧 ZIP”保留原始像素和当前顺序。两入口均保存正式文档；重开及结果撤销重做不重新加工，取消后的草稿可以明确重试。

旧蓝图导入显示迁移及丢弃项。AI 自然语言流程先保存严格提案并预览，再按用户明确指令执行。已执行修订关联固定任务；再次执行应先检查原任务，必要时修订并重新预览。

PSD 在 Krita 检查图层、透明度和合成；Godot 的自动导入与运行仅用于固定可信工程和既有导出器。AI 新生成脚本先审阅，再取得运行授权。
