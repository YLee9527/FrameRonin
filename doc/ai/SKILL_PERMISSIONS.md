# Skill 权限与 AI 结果

Skill 使用当前 Codex 会话的工具与权限。认证、记忆、AGENTS.md、技能发现和原生 ImageGen 输出目录由宿主管理。Skill 不宣称清除宿主上下文，不复制凭据，不修改用户配置，不另起 App Server 或自动切换提供方。独立 App Server 隔离调查保留为历史证据。

模型按已选正式素材版本解析参考图，核对真实文件与内容并查看，然后传给原生工具。本地引擎只读取校验的项目版本和本任务输入副本，算法适配器禁用外部网络读取。提案不包含任意文件路径、命令或可执行脚本；保存与预览只校验，不调度加工。

`ai-begin` 记录固定样本尝试；实际调用前 `ai-mark --state running`。每个样本最多 3 次，额外尝试由用户明确触发。超时、断线或不明确结果标记 unknown，核对原调用后才能接收或判定失败。unknown 接收需质量记录明确 `reconciled: true`，该标记依赖代理对宿主调用的实际核查，不是服务端自动证明。

ImageGen 产物经完整解码、视觉检查后使用 `ai-accept --attempt <id> --file <原生 PNG> --state succeeded|quality_failed --quality <质量 JSON>` 保存副本。登记再次检查执行代次；产物版本、任务完成和质量结论在同一事务中更新。质量失败保留结果，不混同调用失败。不能先普通导入再把任意版本标为 AI 成功。

取消先使本地结果失效，记录 cancel_requested；迟到结果不能成功登记。宿主调用是否停止、最终是否产生文件需单独核对；技能不能虚构原生服务取消接口。AI 生成 Godot 脚本仅保存为待审阅文件；审阅后获得运行授权才能运行。可信既有场景导出测试不扩大到新脚本。
