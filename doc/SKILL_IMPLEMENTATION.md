# FrameRonin Local Skill 实施基线

用户已选择以 Codex Skill、本地确定性处理引擎和可视化工作台交付。独立 Tauri `.app`、独立 App Server 集成、macOS 窗口隐藏及签名验收属于原桌面方案，不作为本次 Skill 的交付方式。原方案的完整业务功能、三语界面、素材版本、严格提案校验、取消、资源预算、输出校验、文档及阶段提交要求继续保留。

## 权限边界

技能运行在宿主 Codex 会话中，使用宿主已开放的内置 ImageGen；不另起 App Server，不复制认证、不读取用户凭据、不调用代充 API，不打开 Gemini Gems。宿主的系统指令、用户指令、记忆及技能发现由宿主管理；技能不能自行清除已注入上下文，不宣称独立上下文隔离。

本地引擎仅处理正式项目中已导入的素材版本及受控输出。自然语言提案使用操作白名单、参数范围和稳定素材版本；预览不加工，明确执行后才产生结果。取消先使结果失效；AI 未知状态先核对，有限重试最多 3 次。AI 新生成脚本先审阅再授权运行。内置 ImageGen 的默认输出由 Codex 管理，选定结果经解码、校验后导入正式项目；不声称可以修改其默认落盘路径。

## 完整范围

保留视频、GIF、图片加工、RoninPro 非 NFT 工具、所有蓝图节点与 13 个预设、Rseprite、地图、游戏测试、PSD/Godot/ZIP 导出、AI 模板与编辑。绘制、图层、时间线、蓝图拖拽及地图拖拽由本地工作台承载。钱包、NFT、FRAME 业务仅留在原始参考归档，不进入交付模块。

新技能名为 `frameronin-local`，源码放在 `skills/frameronin-local/`，完成后安装到用户技能目录。保留已有远程 `frameronin` 技能。npm 是工作台包管理器；现有未提交的 pnpm 文件不改动、不提交。
