# macOS 完整迁移实施基线

状态：已批准实施；前置验证未完成。原始代码基点为 `4472253`，当前分支 `main`。本文件记录实施约束，不表示任何未交付功能已经实现。

## 产品与技术

Apple Silicon，macOS 14 起；Tauri 2、React、TypeScript、Rust、SQLite，沿用 npm。素材库、画布、参数面板、时间线、任务列表采用 macOS 交互，保留中文、英文、日文。移除钱包、NFT、FRAME 业务。

保留原仓库已实现的媒体、像素、RoninPro、蓝图、Rseprite、地图、游戏和导出功能。Python 3.11、Pillow、rembg、OpenCV、FFmpeg/ffprobe 封装为本地运行时，Rust 负责调度。首版交付本机安装的开发版 `.app`；公开签名、公证、更新提供文档，发布另行安排。

AI 改用 Codex CLI 内置 ImageGen，不通过外链 Gemini Gems、代充 API 或其他提供方替代。本机 `0.154.0` 是协议调查基线，尚不是通过验收的生产兼容版本。

## 执行与数据约束

- 提案仅输出结构化方案；生成仅开放内置 ImageGen 及所需参考图能力。关闭无关记忆、指令、技能、插件、MCP、hooks；检查实际模型输入、工具目录和文件访问，无法证明时阻断。
- Codex 管理自身认证；不修改用户配置、不复制凭据、不静默切换提供方。参考图来自校验过的选定版本和任务输入副本，优先内联。取消或断线后状态不明确时先核对，禁止自动重生成。
- 操作注册表定义类型、范围、输入输出、处理方式和资源估算。AI 提案拒绝未知字段、操作、端口、失效版本、重复 ID、环路和超限；旧蓝图兼容导入单独展示修正与丢弃项。
- 项目格式从版本 `1` 开始，使用稳定 ID、相对路径、素材版本、SQLite 索引和任务记录。导入保存副本，结果追加版本；待完成记录、临时文件、校验、原子重命名、事务及启动核对保证一致性。
- 耗时计算进入可取消 Worker 或后台进程；结果经统一完成接口复核任务 ID、执行代次和取消状态。取消 1 秒反馈、5 秒停止本地计算；迟到结果不得登记成功。
- 关闭主窗口先成功保存再隐藏，保留 WebView 和 Worker。保存失败保持可见；退出统一处理窗口、菜单和快捷键、保存与任务等待或取消。
- 文档撤销覆盖绘制、擦除、图层状态、帧增删复制及时间、蓝图和地图布局。加工与 AI 撤销仅切换已有版本，重做不生成；导出文件不随撤销删除。
