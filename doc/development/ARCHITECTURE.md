# 架构与开发

Skill 入口只加载当前任务所需参考；生成由宿主内置 ImageGen 承载。确定性加工通过 `scripts/frameronin.py` 执行，私有 Python 3.11 环境隔离依赖。工作台保留 React/TypeScript 原处理库和编辑器，不直接导入 reference。

项目格式 1 使用 SQLite WAL、文件锁与不可变素材文件。导入先复制、解码和校验，登记待完成记录；原子重命名后事务写入版本。后台任务拥有独立进程组，取消先使执行代次失效，再终止进程。多产物先全部准备，统一完成事务才发布版本和成功状态。

原 TypeScript 算法由私有 Node 22 进程调用，Canvas DOM 适配使用 `@napi-rs/canvas`，避免依赖可见浏览器页面。它仅读取任务输入副本及包内固定资源，禁用算法网络读取；输出限制在任务目录。Python 监控整个进程族，Node 与其内存计入同一预算。适配器改变的是运行环境，像素等价性仍须逐项对照。

HTTP 服务仅绑定 127.0.0.1；写入检查 Host、Origin 和自定义请求头，禁止外部网页直接提交本地任务。返回文件按正式版本和 SHA-256 解析，不接受任意磁盘路径。AI 请求是待执行文档，不由网页直接调用模型。

开发使用 npm，私有运行时及构建产物不入 Git。新增操作必须同步注册表、参数校验、资源预算、处理实现、验收样本与文档。原有算法复制后修改应单独记录与像素对照，避免把旧缺陷无声改变当作复刻。

调度队列采用独立私有 SQLite 与 dispatcher 进程，同一安装串行处理全部项目的任务。排队不分配处理进程；浏览器关闭不停止后台任务。调度器重连只观察已有受控进程，状态不明确时不重跑。运行前复制并核验全部选定输入，避免加工期间从项目读到不同内容。

Rseprite 的文档快照共享不可变像素引用，历史覆盖绘制、帧操作、时长与已有图层状态。保存将改变的像素写为版本，文档仅保留引用；前端离开保护等待保存完成，修订冲突保持页面并允许另存副本。

RoninPro 的缩放、统一尺寸与查重共享 managed image tool 适配器：先导入正式版本，从服务端元数据取得缩略图和尺寸，再调用任务队列；输入数组或参数签名改变时只保留正式结果，不覆盖新视图。预览与拖入暂存分用缩略图、完整文件 URL。大列表按页渲染。

平滑 Canvas 缩放保留在专用 Worker：不同 Canvas 库在缩小滤波及半透明舍入上存在实测差异，不能以构建或近似输出替代原算法对照。队列后台进程等待带执行代次的 Worker PNG 并独占结果登记；浏览器不能直接设置任务成功或版本 ID。该路径与其他任务共享串行排队、取消、恢复及完成事务。整个浏览器退出时任务心跳会过期；页面内导航不销毁执行闭包。当前浏览器进程实际联合峰值与输入准备阶段的完整取消仍待验收。
