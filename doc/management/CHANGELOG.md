# 变更记录

## 0.1.0 开发检查点 · 2026-10-14

- 任务转为持久化串行调度，输入冻结复制校验，取消先失效，完整输出校验避免长占写锁。
- AI 结果统一发布；未知状态、取消请求、宿主最终状态及质量分别记录。
- 严格提案保存修订、输入快照和唯一执行任务；历史蓝图迁移仍使用独立兼容入口。
- Rseprite 统一撤销，像素版本与文档保存、重开、自动保存、离开保护和另存副本。
- 8192 图像与 1000 帧 ZIP/GIF 固定样本通过；Godot 无 AI 脚本的可信工程验证通过。
- 三语快捷键避免单字母冲突；暂存栏避开导航；素材缩略图有界；依赖审计清零。
- 修正原功能登记的重复 ID 和未实现路线图归类。完整模块、AI 质量和最终安装验收继续进行。
