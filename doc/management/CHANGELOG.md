## 2026-10-14：地图文档与后台导出

地图布局、素材版本、羽化、视图与显示状态进入正式文档，支持自动保存、重开、另存和统一撤销。连续重叠滑杆调整合并为一步；卸载同时撤销图像、羽化和可见状态。保存条移到工具栏下方，地图三语入口与操作同步补齐。异步导入检查当前编辑状态，批量恢复合并计算已保留图片与待接受图片的预算。

PNG、分层 PSD、Godot 包和邻接模板迁入受控后台 Node，保留原算法，统一发布正式版本；羽化预览与旧 JSON/ZIP 状态读写移入 Worker。ZIP 先核对中央目录、路径、总解压体积，并对实际解压流设置上限，取消和离开停止相关 Worker。

固定 64px 双图样本的三种羽化组合：PNG/PSD 合成、三个新 Worker 预览、邻接模板与原浏览器严格 RGBA 相等。真实地图工作台通过保存/重开、10% 羽化、卸载撤销、ZIP 恢复的一次撤销、平移缩放恢复、PNG/PSD/Godot 下载及正式版本 SHA 核对。12×1024 地图 UI 取消控件在导出后 291ms 可用，已启动的进程族 0.014s 内停止，结果为空；独立后台取消样本也通过。新 Godot 导出在 4.7.2 可信无脚本测试工程完成导入和三帧运行。

实际修正 64px 图块控件拦截相邻点击，以及文档和语言菜单被全屏地图遮挡的问题。旧 JSON v1 视图撤销、4/8/12 分割、水印结果版本撤销/重做通过；19 Python / 20 JS 回归、构建与相关检查通过。

新 PSD 的 Krita 原生工具仍报告锁屏，不能以像素对照代替本次原生打开验收；旧原生样本记录保留。完整地图负向/导入覆盖、联合内存实测、其余工具、全 AI 模板与独立分发继续验收，S2/S3/S4 不升级为完成。
