# 蓝图和提案

旧蓝图版本 5、6、7 使用兼容导入，必须显示修正与丢弃项。AI 提案使用严格校验：未知操作、参数、节点、连线和端口直接报错；唯一 ID、端口语义、环路、输出与素材版本必须全部有效。两种入口不得共用静默清理。

`preview` 仅校验、估算，不执行加工。提交前再次校验输入版本内容。工作台提供蓝图节点与连接编辑及 13 个内置预设；每个预设需实际样本验证，能够读入 JSON 不代表加工通过。

操作参数以注册表为准，不接受命令、脚本或任意读写路径。自然语言描述不能直接成为可执行代码。输出引用正式素材版本，保留提案修订号；修改提案或输入后必须重新预览。

正式 AI 提案使用 `proposal-save --file <严格任务 JSON> --references <明确选定版本...>`。返回稳定提案 ID、修订、预算和输入快照，保存不会执行。用户明确执行后调用 `proposal-execute --proposal <id> --revision <已审阅修订>`。若提案或素材当前版本改变，必须保存新修订并重新预览。已执行修订关联唯一任务，先检查原任务，不能重复领取同一修订。
