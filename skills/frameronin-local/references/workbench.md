# 可视化工作台

`scripts/frameronin.py serve --project <project> --port 8765` 启动本机工作台，地址为 `http://127.0.0.1:8765`。打开内置浏览器或系统浏览器；服务仅绑定环回地址。先执行运行时安装的 `--workbench` 构建步骤。后台媒体进程与标签页独立；需要宿主 Canvas 的任务必须保留该浏览器标签，离开工具页可继续，关闭标签则失联核对。中断服务后重新启动会核对未完成记录。

工作台承载原仓库的三语工具、绘制擦除、图层、帧时间线、蓝图拖拽、地图拼接邻接羽化、接缝预览、控制测试和无限地图。保存到正式项目后再关闭文档；保存失败保留当前编辑内容。AI 模板入口创建本地请求供 Codex 执行，不打开外部 Gems。

加工与 AI 撤销只切换已有版本，重做不重新生成；文档历史记录编辑操作。PNG、精灵表、ZIP、索引、PSD 与 Godot 导出保留原实现。PSD 在 Krita 核对图层、透明度及合成，Godot 4 在固定可信工程中导入运行。尚未运行的互操作验收必须明确记录。

Rseprite 现已接入项目文档：绘制内容保存为正式 PNG 版本，图层、帧与时长保存为文档修订；改变后自动保存，离开前等待保存。修订冲突保留当前内容，使用“另存文档副本”保存本次编辑。重开经过严格字段、引用、尺寸与内存校验。

绘制、擦除、重置、已有图层状态、帧增删复制与时长进入同一有界撤销栈。原仓库的 Rseprite 导出尚属未实现路线图，不作为已复刻功能宣称。地图/蓝图保存与完整前端计算取消仍按功能清单验收。

地图文档现在保存源图与相邻图的正式版本、布局、羽化、边框/可见状态、重叠参数、细分数及平移/缩放/选中位置。自动保存和另存沿用修订检查；重开不会重新导入已有版本。导入、替换、卸载、羽化、扩展及布局设置可撤销；一次滑杆拖动为一步。恢复旧 JSON v1 或 ZIP v2 也作为一次编辑，保留原导入文件。

地图 PNG、分层 PSD、Godot 包和邻接模板使用持久化后台任务，可在项目任务列表查找正式结果；离开页面不停止这些后台任务。羽化预览与旧状态 ZIP 读写使用可取消 Worker。状态 ZIP 是便携导出，离开编辑器会取消尚未完成的 ZIP 读写；先等待下载完成。预算拒绝与读取失败保留现有内容并显示错误。保存历史不删除已经导出的文件。

GIF 拆分与序列转 GIF 使用原浏览器兼容算法的持久化后台任务，带进度及取消。原 GIF 的处置和透明块逻辑、合成逐帧调色板、第一帧尺寸及全局间隔保持原行为。输入改变时保留项目内的结果，不覆盖新选择；离开工具页后在项目面板读取。多图裁切/扩边合成、规则/透明拆分、三种拼接及空白帧同样由受控后台执行。

序列编辑器提供正式文档与有界撤销：排序、帧增删、空白帧、参数和已登记结果可保存/重开。排序手柄支持方向键、Home/End，Command/Ctrl+Z/Y 撤销重做。分页缩略图保留原始文件用于加工及拖入暂存；裁切预览使用原尺寸坐标。大动画在预算内显示静态缩略图，下载保持全部帧及原尺寸。已通过千帧工作台导出、保存冲突、另存、迟到读取/结果保护和取消；完整范围与未验收项详见仓库验收记录。

视频水印入口直接使用本地项目任务，支持进度、取消、结果播放与 MP4 下载，无需另建旧 Web 后端。离开页面后任务继续，正式结果在项目素材与任务中读取；离开后不额外下载视频到前端。原时序检测可能留下残影，下载后应检查实际修复区域及音轨。

像素转化页五种模式均为后台任务，可取消并在离开页面后继续。先将选定原件导入项目，再加工并追加正式结果；大图仅用有界预览，框选坐标对应原图。结果显示实际处理尺寸，超预算报错而不缩小。

像素文档保存原件、选区、全部模式参数和已有结果。参数与结果统一撤销/重做，完整拖动为一步；重做结果不重新加工。保存冲突时保留编辑，可另存副本；迟到读取不会覆盖新编辑。历史按唯一保留文件计费，超过预算裁剪最远历史，正式素材版本仍保留。

RoninPro 的统一尺寸、切分查重和自定义缩放可以保存、另存和重开正式文档。输入、参数、已有 PNG 与报告统一撤销/重做；结果不会因重做再次加工。查重 4096 格按页显示，保存和重开保留全部帧；修改参数后仍显示上次结果并明确提示。

自定义缩放和独立精细入口的绘制保存为单独 PNG 版本，画笔、橡皮、连通擦除、选区移动与重置可统一撤销。独立入口支持静态 PNG/JPEG/WebP，最大 20 MiB；源图替换、删除也可撤销。保存及导航会等待画布编码；取消或编码失败仍显示未保存，可重试或明确放弃该笔画。连通擦除、选区移动、解码和编码在可取消 Worker 中完成，超预算明确拒绝，不静默缩小。下载始终为实际 PNG，JPEG 需要浏览器 ImageDecoder 能力。常规处理与蓝图结果可转入精细入口，已登记的蓝图版本沿用引用。其余入口与动画图片兼容继续按验收表迁移。

常规处理的裁切、抠图、硬边/平滑缩放、内描边、底部扩展及三个一键配方统一使用受控 Worker 任务。原图预览最长边 1024，坐标、取色和输出仍使用原图；预览与取色可单独取消、重试，取色期间暂停加工。正式 image-normal 文档保存源图、参数、独立主结果与抠图预览；源图/参数/结果可撤销、重做、保存、另存和重开。修改参数后提示仍显示上次结果，必须明确重新执行才应用新参数。原算法对照、真实取消及保存冲突等验收详见仓库记录，其他模块与完整格式/内存验收继续进行。

“扩图与缩图”使用受控宿主 Worker 和 image-expand-shrink 正式文档。原件、网格行列、格子尺寸及已有 PNG/报告可保存、另存、重开和统一撤销；下载与暂存保留实际 PNG，显示使用有界缩略图。参数变化不接收旧任务结果，旧结果仍保留在项目中；离开工具页后继续，保留浏览器标签直到完成。

零散切图保留自动识别、手动新增/移动/缩放/删除/清空、名称列表、行列排序、缩放与尺寸标签，以及 PNG/JPEG/WebP ZIP。该原组件没有实际固定网格入口；网格/自定义切片使用独立工具。sprite 框不适用“按行命名”，此选项仅对保留网格元数据的框有效。

scatter 文档保存源图、完整设置、画框和已有 JSON/ZIP。完整手势及结果统一撤销/重做；“下载已有 ZIP”直接复用文件，不增加任务或版本。参数改变时提示旧 ZIP 尚未更新，点击新导出才重新加工。输入准备、源图预览和加工均可取消，预览可以重试；失败仍保留现有图与具体原因。保存冲突可另存，读取过程中继续编辑不会被旧文档覆盖。

自定义切图保留智能检测、网格与区域裁切、L7 手动拖线、行带同步错位、单行折线、透明/镜像重排、TXT 及八种补边预设。custom-slice 文档保存原件、参数、方案和已有 ZIP/PNG，统一撤销、重做、另存及重开；复用结果不重新加工。TXT 兼容导入明确展示修正与丢弃项。

源图预览最长边 1024，帧预览最多 24 张；下载与暂存使用全部原尺寸帧。原件准备、预览和加工可取消，预览可重试；失败保留已有文档。参数变化和未结束切线手势阻止迟到内容覆盖；修订冲突阻止离开，可另存副本。自动检测与切分属于同一次明确操作，保存重开和历史操作不会重新触发。离开工具页后加工继续，保留浏览器标签直到完成。
